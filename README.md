# Webtech-Exp10
Aim :
To develop a Node.js application to handle HTML registration forms and store user details in MongoDB.

Description:
Node.js allows you to run JavaScript outside the web browser. Used to create both client and server-side applications (Full Stack Web Application Development). Node JS is single threaded application environment. A single response for all the requests. NodeJS best suitable for creating websites and web applications which contain less . CPU-intensive tasks.

Procedure:

1.	Open Visual Studio Code and create a project folder.
2.	Create a JavaScript file named server.js.
3.	Install Node.js and verify the installation using node -v and npm -v.
4.	Import the required Node.js modules.
5.	Create a server using the http module.
6.	Use the createServer() method to handle client requests.
7.	Write the response using response.write() and end it using response.end().
8.	Specify the server port number using the listen() method.
9.	Run the program using the command node server.js.
10.	Open a web browser and enter http://localhost:3000 to view the server response.
